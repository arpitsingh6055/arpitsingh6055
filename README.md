## `07` · A few principles I’m learning by doing

- **Start with the user’s problem**, not the technology looking for a use case.
- **A demo is not a product.** Reliability, recovery, evaluation, and usability matter.
- **Agents need boundaries.** Tool permissions, observability, and human approval should be designed—not bolted on.
- **Measure outcomes.** Track whether a solution improves task success, time, quality, adoption, or cost.
- **Show the work.** Clear assumptions, reproducible experiments, honest limitations, and useful documentation beat hype.
